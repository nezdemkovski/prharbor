# PR Harbor: подключение только через GitHub CLI

> Обновление 2026-10-05: bridge удалён из production-кода; `gh` запускается напрямую без App Sandbox. Проверка новой версии: [direct CLI](direct-cli-2026-10-05.md). Результаты ниже относятся к предыдущей сборке.

По запросу пользователя встроенный GitHub sign-in и ручные токены удалены. На момент этой проверки единственный production-транспорт данных GitHub — `gh api` через sandbox bridge. Приложение хранит только выбранный аккаунт, API URL и путь bridge, а аутентификацией занимается CLI.

Удалены реализации device flow, OAuth refresh, token validator, общий Keychain credential wrapper, OAuth client ID, OAuth response models и их Xcode references. Первый экран и Account теперь предлагают только Connect GitHub CLI / Reconnect / Disconnect. GitHub Enterprise поддерживается через API URL. README обновлён.

`GitHubClient` строит и декодирует общие GraphQL-запросы. `GitHubAPITransport` отделяет запросы от исполнения; единственная production-реализация — `GitHubCLI`. HTTP fixture transport находится только в test target. Все запросы за PR, CI/review, историей, стеками, текущим пользователем и пользовательские rebase-операции идут через CLI. Изображения аватаров остаются обычными загрузками по URL через ограниченный image cache.

## Миграция

- Сохраняется активное CLI-подключение. Остаточная CLI metadata от ранее выбранного OAuth или Disconnect не подключается автоматически.
- Прежний ключ выбора способа входа удаляется из defaults.
- Однократная фоновая очистка вызывает `SecItemDelete` только для generic-password записей `githubToken` и `githubSession`, service `com.nezdemkovski.prharbor`. Содержимое credentials не читается. Данные и вход самого gh не меняются.
- Cleanup не открывает authentication prompts. Если Keychain отклоняет удаление, отображается ошибка с Retry; отметка об успешной миграции выставляется только после успешного удаления обеих записей / подтверждения их отсутствия.
- Disconnect удаляет только локальный выбор аккаунта PR Harbor. Смена активного gh-аккаунта требует явного Reconnect; in-flight account check не может вернуть клиент после Disconnect или новой connection generation.
