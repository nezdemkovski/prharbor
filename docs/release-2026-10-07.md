# v0.2.0 release preparation

User authorized publication with free ad hoc signing for personal use on 2026-10-07. Source version is 0.2.0, build 17, minimum macOS 27. Release notes explicitly retain the known dense-list scrolling limitation.

The release workflow runs the hosted Swift tests, builds Release, then uses `Scripts/package-release.sh` to stage and ad hoc sign the bundle with Hardened Runtime before creating the DMG. The packaged app is strictly verified, the disk-image checksum is verified, and SHA256SUMS is generated. DMG and checksum manifest are published together. The Homebrew cask declares macOS Golden Gate, Apple silicon and gh dependencies.
